# DAPT V4 + V5 + Binary/Ternary 不对称性 交接 (2026-05-10)

## 目的

延续 [paper draft v3](../../paper/drafts/paper_draft_v3.md) §4.5 三个结构性混淆的诊断（domain mismatch / Stieger 占主导 / channel-count 异质性），追加两个 surgical-fix 的 DAPT 变体：

- **V4**：3 个域对齐数据集（Cho2017 + Ofner2017 + Schirrmeister2017）+ strict artifact filter，针对 (1) domain mismatch 和 (2) Stieger 占主导
- **V5**：单源 Stieger2021（60 ch）+ 原 basic filter，针对 (3) channel-count 异质性

每个变体先做 cross-subject ternary gating（V2 protocol）；passing → 全 6 条件矩阵；failing → 写进 §4.5 作为 negative result。

实际执行时 [the user pushback](../../C:\Users\zhang\.claude\projects\c--Users-zhang-Desktop-github-EEG-BCI\)（V4 ternary +0.22 pp 不该被快速否决）促使我们追加在 cross-subject **binary** 上对 V4/V5 + V1/V2/V3 全部重测——这暴露出本文最重要的发现：**DAPT 负迁移在 task 上严重不对称——binary 一致显著负，ternary 接近零或弱正**。

## 关键发现（TL;DR）

1. **完整 12-cell 矩阵全部负向或近零**（V4 + V5 各 6 条件 = 12 cells；0/12 正向显著）。DAPT 失败不是 cross-subject 特有现象——within / transfer 上同样负向。Caveat #6 ("DAPT 是否仅在 cross-subject 失败") 闭环关闭
2. **V5 在 6/6 条件上比 V4 更差**（仅 transfer binary 微弱反例 −1.22 vs V4 −1.67 但都不显著），且**显著性更广**（V5: 5/6 cell p ≤ 0.10；V4: 2/6 cell p < 0.05）→ "channel-count 单一化"作为 surgery 不仅没救援，反而**系统性恶化**
3. **V4（3-set + strict filter, best DAPT loss 0.001914）**：strict filter 把 cross/ternary 拉回 +0.22 接近零，但 **cross/binary 仍 −1.61 pp p=0.008**、**transfer/binary −1.67 pp p=0.026** —— 域对齐 + 数据净化都救不回 binary
4. **Task asymmetry（binary 比 ternary 更负）在 V4 清晰，V5 缩小**：V4 binary cells 平均 Δ ≈ −1.5 pp、ternary cells 平均 Δ ≈ −0.2 pp（gap ≈ 1.3 pp）；V5 binary 平均 Δ ≈ −2.3 pp、ternary 平均 Δ ≈ −1.6 pp（gap ≈ 0.7 pp）。V5 对粗与细同时损伤，asymmetry 模糊
5. **没有 DAPT 变体通过 Stage 3 gate**（paired t-test p<0.05 + 正向 Δ）；Stage 4 全 6 条件矩阵作为"reviewer-defense"补跑，全部确认负向
6. **残留机制候选**收紧到一个：**MI 粒度错配**（粗 hand/leg/upper-limb MI vs 细 finger-level MI），其它两个候选机制（Stieger 占主导、channel 异质性）被 V4/V5 surgery 排除

## V4 Strict Filter 详情

实现入口：[scripts/pretraining/preprocess_mi_datasets.py:filter_segments_strict()](../../scripts/pretraining/preprocess_mi_datasets.py)，CLI flag `--artifact-filter strict`。两阈值并行 AND：

- **300 µV peak**：`np.max(np.abs(segments), axis=(channel,patch,sample)) < 300`
- **per-channel kurtosis > 10**：`scipy.stats.kurtosis(seg, axis=time, fisher=True)` 任一 channel 超阈值则丢弃整段

为什么不用每个数据集"官方 trial-level annotations"（原计划）：现有 LMDB 仅存 `(n_ch, 30, 200)` pickle，无 per-segment metadata；要重现 trial-level filter 需要从 raw 重做 trial-aligned extraction，会破坏 V1/V2/V3 segment 定义、影响可复现性。strict filter 是**与官方 annotations 同物理动机的 universal substitute**——同时捕获 eye-blink、motion artifact、broken channel pulse 这些 trial-level annotations 设计要标的同一类异常。

### Task asymmetry 跨 paradigm 复现

按 V4 / V5 分组、按 task 平均 Δ：

| Group | binary 平均 Δ | ternary 平均 Δ | gap |
|---|---|---|---|
| V4 (3-set + strict filter) | (−1.10 + −1.61 + −1.67) / 3 = **−1.46** pp | (−0.56 + 0.22 + −0.32) / 3 = **−0.22** pp | 1.24 pp |

## 残留机制收紧（§4.5 重写方向）

V1/V2 已排除：domain heterogeneity 之外，下面三个候选随 V4/V5 实证一一筛除——

| 候选机制 | V4/V5 检验 | 检验结果 |
|---|---|---|
| (1) Domain mismatch（粗 MI vs 细 finger MI）| V4 用最接近 finger 的 3 数据集 + strict filter | binary 仍 −1.61 pp p=0.008 → **未排除**，但 surgery 不足以救援 |
| (2) Stieger 占主导（V2 时 ~79%）| V3 (Stieger 减权 → ~30%) 已部分检验；V4 完全去除 Stieger | binary 仍负、ternary 仍接近零 → **基本排除** Stieger 是元凶 |
| (3) Channel-count 异质性（7 种通道数）| V5 (单一 60 ch) 直接消除 | V5 在 binary/ternary 上**双向恶化** → **强烈反方向**——通道多样性不是 bug，是保护因子 |

**剩下能解释 task asymmetry 的只有 (1) 的某个版本**：粗 MI 的 MAE pretext loss 学到的是"哪个肢体在动"的低频空间包络，下游 finger-level binary（食指 vs 中指，**同手**）需要的是 DAPT 没学到的细粒度区别；而 ternary 的 rest 类（不动 vs 运动）正好用 DAPT 学到的粗粒度就能识别——所以 ternary 不那么坏。

V5 反向恶化的解释：当 pretrain 只看 60 ch 单一几何，且这个 60 ch 与下游 128 ch 几何错位（不同 ACPE 上下文），模型会把粗 MI 的空间编码"过拟合"到 Stieger 的电极阵列——下游 fine-tune 时 ACPE 必须从头校正这套错位的空间先验。V1/V2/V3 的 7 种通道数反而强迫 backbone 学 channel-agnostic 表示。

## Caveats（写论文时必须 disclose）

1. **V4/V5 同时变更了"数据组成"和"过滤强度"**：V4 用 3 数据集 + strict filter（300 µV + kurtosis>10）；V5 用单源 + basic filter（500 µV mean-abs only）。如果 V4/V5 上看到的 binary 负向显著弱化（实测：没有），无法立即归因到"过滤"还是"数据组成"。**未来如做 V6（V2 数据组成 + strict filter）**，可隔离过滤效应。当前结论是"strict filter + 域对齐都救不回 binary"，所以 V6 的边际价值不高，没安排。

2. **Stieger filter scope 不一致**：V4 三数据集都过了 strict filter，V5 的 Stieger 没过 strict filter（仅 basic 500 µV mean-abs）。这是 wall-clock 妥协（重处理 Stieger ~25h）。V5 的 binary 负向虽然最大（−2.77），不能 100% 排除"Stieger 段比 V4 三数据集更脏"的可能；但 V1/V2/V3 共用 basic filter，binary 也都负，所以 filter scope 不太可能是 V5 binary 显著恶化的主因。

3. **V1/V2 cross-subject results 没有进 ExperimentDB**：V1/V2 时期评估走了 ad-hoc JSON cache 路径，没双写 DB。本 handoff 表中 V1/V2 的 t-test 是用 paper analysis md 中记录的 per-subject acc + 当前 baseline 重做的，与 V3/V4/V5 走 DB 路径不完全对称。

4. **Baseline registry 漂移警告**：`baseline_refs` 表中 cross-subject binary 同时标 `20260324_0023`（有 results）和 `20260330_0709`（is_baseline=1 但 `subject_results` 为空）。本 handoff 报告的 t-test 用前者；下次更新 baseline 时需核对 [docs/dev_log/experiments/baseline_registry.md](../../docs/dev_log/experiments/baseline_registry.md)。

5. **V4 small-data caveat**：V4 仅 4,937 段（Cho 1,135 + Schirr 3,310 + Ofner 492），Schirrmeister 占 67% 采样权重。意味着 V4 的"3-set 域对齐"实质上偏向 Schirrmeister 主导（128ch 通道匹配下游，但 motor execution 而非纯 imagery）。strict filter 让 Cho/Ofner 大幅减重的副作用。

6. ~~**Within-subject / transfer 评估缺失**~~：**已关闭（2026-05-10 22:29 完成）**。V4/V5 × {within,transfer} × {binary,ternary} 8 cell 全部补完，wall-clock ~3.5h（含 overwatch 等待）。完整 12-cell 矩阵全负或近零，无任何正向显著。

7. **`--further-pretrained-cbramod` flag 已就位**：[run_cross_subject_comparison.py:381-385](../../scripts/experiments/run_cross_subject_comparison.py#L381) 早就有这个 flag（不是 `--pretrained-weights`，详见 plan 中的勘误）。within-subject 和 transfer runner 同样已有等价 flag——即先前 Phase-1 verification 报告"runners 缺 wiring"是错的，无需补代码。

### 新洞察：Transfer 范式对 binary 有"弱化"作用

把每个 version 的 cross binary Δ 和 transfer binary Δ 做差（"transfer 比 cross 改善了多少"）：

| Version | cross binary Δ | transfer binary Δ | rescue (transfer − cross) | rescue 是否把 p 拉出显著区 |
|---|---|---|---|---|
| V1 | −1.84 *** | −1.10 n.s. | +0.74 pp | ✓ (0.009 → 0.17) |
| V2 | −1.25 *** | −0.74 n.s. | +0.51 pp | ✓ (0.025 → 0.25) |
| V3 | −1.46 (.) | −1.01 n.s. | +0.45 pp | ✓ (0.051 → 0.26) |
| V4 | −1.61 *** | −1.67 *** | −0.06 pp | ✗ (反而稍差) |
| V5 | −2.77 *** | −1.22 (.) | **+1.55** pp | 部分 (0.014 → 0.086) |

**V1/V2/V3（多数据集 DAPT）transfer 范式都能把 binary 负迁移"洗"到 n.s.**——per-subject 微调似乎能部分修正 DAPT 学到的不利偏差。
**V4（3-set 域对齐 + strict filter）transfer 反而没救援**——可能因为 4,937 段太小、DAPT 学到的偏差过于"集中"于域对齐先验，per-subject 微调没空间洗掉。
**V5（Stieger-only 60 ch）transfer 救援最大**（+1.55 pp）但不够把 p 拉到 >0.10 安全区——单源单几何的偏差最强烈，但也最容易被 21 个 128 ch 受试者的微调"反向校正"。

ternary 上则反向：cross → transfer 没有系统改善（V1/V2 持平 +0.65/+0.18，V3 略升 +0.47，V4/V5 略降 −0.54/−0.30）——因为 ternary 的 rest 类已经吸收了 DAPT 学到的粗粒度区别，transfer 无须再校正。

### 18-cell 矩阵对 §4.5 的额外贡献

1. **没有任何 paradigm × task 组合让 DAPT 翻正**——上一节的"12-cell 全负或近零"在 18-cell 上加强：6 个新 cell 也没破例。
2. **Transfer rescue 是 DAPT-多样性数据**（V1/V2/V3）的特性，不是普遍现象——V4/V5 surgery 后丢失了这个 fallback。
3. **V3 transfer ternary +1.09 pp（p=0.11）是整个 18-cell 矩阵里最接近正向显著的 cell**——但仍 p>0.10。这说明 Stieger 减权后的 V3 在 transfer/ternary 上展现出"接近能用"的正向，但不足以推翻"DAPT 失败"结论。

## 追加段的 Caveats（与上文 §Caveats 并列，本次新增）
