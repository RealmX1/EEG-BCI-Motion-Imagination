# Extra Online Sessions 实验分析：Per-Session 策略（默认）

> **实验日期**: 2026-03-24 ~ 2026-03-25
> **配置**: 128 通道, 16 被试, imagery paradigm, binary task
> **测试策略**: per_session（每步测试对应 session 的 Finetune 数据）
> **数据来源**: `results/20260324_2131_extra_sessions_cache_imagery_binary.json`

## 1. 实验背景

Finger-EEG 原论文（Schwarz et al.）观察到 EEGNet 在加入第二次在线会话之后的额外训练数据时，准确率提升有限。本实验在 EEGNet 和 CBraMod 上以更大被试规模（N=16 vs 原论文 N=5）系统评估这一结论。

### 1.1 渐进式数据协议

| Step | 训练集 | 测试集 |
|------|--------|--------|
| Baseline | Offline + Sess01(Base+FT) + Sess02(Base) | Sess02(Finetune) |
| +Sess03 | 上述全部 + Sess02(FT) + Sess03(Base) | Sess03(Finetune) |
| +Sess04 | 上述全部 + Sess03(FT) + Sess04(Base) | Sess04(Finetune) |
| +Sess05 | 上述全部 + Sess04(FT) + Sess05(Base) | Sess05(Finetune) |

**注意**：每个 step 的测试集不同（分别为 Sess02/03/04/05 的 Finetune 数据）。这意味着跨 step 的准确率变化反映了**训练数据量 + 测试集难度差异**的联合效应，而非纯粹的训练数据贡献。

### 1.2 被试

16 个被试拥有 Sess03-05 数据：S02, S03, S04, S06, S07, S08, S09, S10, S11, S13, S14, S15, S16, S17, S18, S19。

Baseline 来自 ExperimentDB 中各模型的标准 post-HPO within-subject 运行：
- EEGNet baseline: `20260316_1411`
- CBraMod baseline: `20260323_2237`

## 3. 关键发现

### 3.1 与原论文结论的对比

原论文称 EEGNet 在加入额外数据后提升有限。N=16 的结果**修正了这一结论**：

- **群体均值**：EEGNet 从 80.51% 提升至 87.85%（+7.34pp），CBraMod 从 87.23% 提升至 93.36%（+6.13pp）
- **低 baseline 被试获益显著**：baseline < 80% 的被试（S06/S10/S11/S15/S16/S17）平均提升 +15.10pp (EEGNet) / +11.56pp (CBraMod)
- **高 baseline 被试提升有限或略降**：baseline > 90% 的被试平均变化 -0.06pp (EEGNet) / +1.95pp (CBraMod)——天花板效应明显

原论文仅在 5 个被试上观察到"有限提升"，但其中 3 个 baseline 已 >90%。当样本量扩大到 16 个（包含更多低 baseline 被试）时，额外数据的价值变得显著。

### 3.2 EEGNet vs CBraMod

| 维度 | EEGNet | CBraMod |
|------|--------|---------|
| Baseline 均值 | 80.51% | 87.23% |
| +Sess05 均值 | 87.85% | 93.36% |
| 绝对提升 | +7.34pp | +6.13pp |
| Std 变化 | 12.05% → 7.18% | 10.85% → 5.89% |
| 最大单被试提升 | S16: +27.50pp | S16: +24.38pp |

- CBraMod 在所有 step 上的绝对准确率均高于 EEGNet（baseline 差 6.72pp，+Sess05 差 5.51pp）
- 两模型的 **标准差均显著收缩**，说明额外数据使性能更稳定（个体差异减小）
- CBraMod 到 +Sess05 时标准差仅 5.89%，且 12/16 被试超过 90%

### 3.3 被试技能学习效应（User Skill Learning）

BCI 是一个闭环系统——被试在多次 session 中逐渐学会更有效地调制运动想象相关的 EEG 信号。后续 session 采集到的数据通常具有更高的**信噪比**和更清晰的**类别可分性**。这是 per_session 策略结果解读中的关键因素：

- **训练数据质量提升**：+Sess03/04/05 引入的不仅是"更多数据"，而是"更高质量的数据"。被试已经通过前序 session 的在线反馈学习了 BCI 操控技巧，后续 session 的神经模式更加稳定和可区分
- **测试数据也更容易**：per_session 策略中后续 step 的测试集来自更晚的 session，被试 BCI 技能更成熟，测试数据本身的可分性更高
- **双重叠加效应**：per_session 下观察到的准确率提升实际上是**训练数据量增加 + 训练数据质量提升 + 测试数据质量提升**三者的叠加，而非纯粹的数据量贡献

这意味着 per_session 策略的 +7.34pp (EEGNet) / +6.13pp (CBraMod) 提升**高估了训练数据量本身的价值**。需要结合 fixed_combined 和 fixed_sess02 策略的结果来分离这些因素（详见策略对比分析文档）。

### 3.4 非单调路径

多个被试在中间 step 出现性能下降后在最终 step 回升（如 S06 EEGNet: 68→88→74→91, S17 EEGNet: 71→83→64→76）。

可能原因：
1. **Session 间 BCI 技能波动**：被试不一定在每次 session 中都保持稳定的操控水平，某些 session 可能状态较差（疲劳、注意力下降等）
2. **测试集难度差异**：per_session 策略下各 step 测试集不同，某些 session 的 Finetune 数据固有难度更高
3. **训练数据异质性增加**：引入质量参差不齐的 session 数据可能短暂干扰模型的决策边界

### 3.5 S09 退化现象

S09 是唯一在两个模型上均出现退化的被试（EEGNet: 99.38→95.62, CBraMod: 99.38→93.12）。可能解释：
- Baseline 已接近完美（99.38%），天花板效应严重
- 后续 session 的神经模式可能与早期 session 有所偏移（如策略调整、电极位置微变），引入这些数据反而增加了训练集的分布异质性
- 这也可能反映被试技能学习达到平台后的正常波动

### 3.6 跨 Session 时间分布差异

后续 session 的数据虽然质量更高（被试技能提升），但与早期 session 之间存在递增的**时间分布差异**（temporal distribution shift）：电极阻抗变化、日间神经变异、被试心理策略演化等。这意味着 Sess05 的数据在帮助预测 Sess02 时，其"分布不匹配"可能部分抵消了"数据质量更高"的优势。

策略对比分析中发现，fixed_sess02（固定测试 Sess02）的增量收益在 +Sess03 后急剧衰减，支持这一假说。详见策略对比分析文档 §3.5.4。

### 3.7 S16 的戏剧性提升

S16 在两个模型上都展现了最大的提升（EEGNet: +27.50pp, CBraMod: +24.38pp）。Baseline 极低（EEGNet 56.25%, CBraMod 70.62%），说明仅用标准数据量时模型无法有效学习该被试的 EEG 模式。额外 session 提供了足够的数据量使模型突破了这一瓶颈。

## 4. 统计检验

### 4.1 配对 t 检验 (Baseline vs +Sess05)

| 检验 | t 值 | p 值 | 结论 |
|------|------|------|------|
| EEGNet Δ vs 0 | t=3.03 | p=0.009 | **显著** (p<0.01) |
| CBraMod Δ vs 0 | t=3.52 | p=0.003 | **显著** (p<0.01) |

N=16 下两个模型的提升均达到统计显著。这与 N=5 时不显著的结果（前期实验 p=0.210/0.058）形成对比，体现了统计功效随样本量增加的改善。

### 4.2 模型间差异

| 检验 | 统计量 | p 值 | 结论 |
|------|--------|------|------|
| EEGNet Δ vs CBraMod Δ (Wilcoxon) | W=68.0 | p=0.923 | 不显著 |

两模型从额外数据中获得的提升幅度无统计学显著差异。EEGNet 的绝对提升略大于 CBraMod（+7.34 vs +6.13pp），但这可能因为 EEGNet baseline 更低，有更多改善空间。

## 5. 局限性

1. **测试集不可比**：per_session 策略下每个 step 的测试集不同，无法严格控制测试难度，跨 step 变化不可直接归因于训练数据量。详见策略对比分析文档。
2. **被试技能学习混淆**：后续 session 的训练和测试数据均受益于被试 BCI 操控技能的提升，无法在 per_session 框架内分离数据量 vs 数据质量 vs 被试技能三个因素的各自贡献。
3. **仅 binary 任务**：Ternary 待运行。
4. **无超参数重调**：所有 step 使用相同的超参数（来自 baseline HPO），未针对增大的训练集重新调参。
