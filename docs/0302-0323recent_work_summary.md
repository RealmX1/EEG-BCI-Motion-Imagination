# EEG 脑机接口项目——近期工作进展

> 2026 年 3 月 2 日 ~ 3 月 23 日

---

## 一句话概括

通过**自动调参、数据质量筛查、额外预训练**三条线并行推进，将脑电解码准确率持续提升，并完成了论文草稿初版。

---

## 核心成果

### 1. 自动超参数搜索（HPO）

用自动化搜索替代人工试参数，让两个模型都找到更优配置：


| 模型            | 优化前    | 优化后    | 提升       |
| ------------- | ------ | ------ | -------- |
| CBraMod（基座模型） | 67.68% | 68.17% | +0.5     |
| EEGNet（轻量模型）  | 52.61% | 60.12% | **+7.5** |


> EEGNet 提升显著，优化后与 CBraMod 差距大幅缩小。

### 2. 数据质量筛查

开发了自动化数据质量检查工具，逐被试扫描异常信号（肌电伪迹、幅度异常等），确保模型训练用的是"干净"数据。

### 3. 进一步预训练（Further Pre-training）

搜集外部脑电数据集，对基座模型做领域适配性预训练：


| 方案      | 准确率          |
| ------- | ------------ |
| 原始预训练权重 | 81.61%       |
| 额外预训练后  | 82.95%（+1.3） |


> 初步验证路线可行，后续将扩大预训练数据量。

### 4. 通道缩减验证

进一步验证了用**少量电极**（4~32 个）替代全部 128 个电极的可行性，为未来低成本设备部署提供依据。其中 32 通道 binary 任务跨被试准确率达 **88.10%**，接近 128 通道水平。
